# Text to System Design Diagrams
## Abstract
This paper presents a novel approach to automating the generation of system design models from natural language specifications. It addresses the challenges of ambiguity and 
complexity in manual model creation by introducing a formal grammar called FRArchD (Functional Requirement in Architectural Design). This grammar is an extension of pre-defined grammar based on laws of physics that facilitate the translation of natural language text into architecture to represent structural specifications. FRArchD is an intermediate representation that can be transformed into SysML or AADL modeling languages. This approach is demonstrated through five use cases, including aerospace and electromechanical domains, showcasing the grammar’s flexibility and effectiveness in capturing salient system features and auto-generating accurate models. The automated generation of SysML models enables future validation through physics-based reasoning on their XML representations. This work’s contributions in the Model-based Systems Engineering (MBSE) field seek to improve the design process and reduce potential errors by providing a systematic and efficient method for automatically translating natural language specifications into formal systems models.
